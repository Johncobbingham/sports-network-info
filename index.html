Sports Network

A private publishing tool by John Ingham, an independent sports commentator.

Sports Network is an internal tool that runs only on my own computer. It helps me publish my own sports commentary videos to YouTube channels that I own.

After I record a video, the tool trims dead air, levels the audio, creates captions, and drafts a title, description, chapters and thumbnail options from my own commentary. It then uses the YouTube API Services to upload the video to my own channel as private, set the thumbnail and add the captions. I review every video myself and decide when it goes public.

The tool is not offered to the public, has no other users, and does not access anyone else's data.
