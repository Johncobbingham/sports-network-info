Privacy policy

Last updated: November 18, 2026

Sports Network is a private, internal tool used only by its owner, John Ingham, to publish his own videos to YouTube channels he owns. It has no other users.

YouTube API Services

Sports Network uses YouTube API Services. By using it, the account owner agrees to be bound by the YouTube Terms of Service. The Google Privacy Policy also applies.

What data is used

  • The tool signs in only to the owner's own Google account, using Google's standard sign-in (OAuth).
  • It uploads the owner's own videos, thumbnails and captions to the owner's own channels, and reads basic information about those channels (for example, the channel name) to confirm where it is uploading.
  • The sign-in token and the IDs of uploaded videos are stored only on the owner's own computer.
  • No data about any other YouTube user is collected, stored, shared or sold. There are no cookies, analytics or tracking on this site.

Revoking access

Access can be revoked at any time on the Google security settings page. Stored tokens are deleted from the owner's computer when access is revoked or no longer needed.

Contact

Questions: contact John Ingham through his YouTube channel's About page.

Data deletion

The owner can delete all locally stored data at any time by deleting the tool's data folder and revoking access (see above). Revoking access immediately stops the tool from reaching YouTube.
